# C Programming Collection

Репозиторий включает программы на языке C: упражнения из книги Брайана Кернигана и Денниса Ритчи (K&R) и решения задач с Codeforces и Timus.

## Структура проекта

* `CodeForces/` — решения задач со спортивных состязаний.
* `Timus/` — архивные задачи Timus Online Judge.
* `kr_exercises/` — упражнения по учебнику K&R по главам.

## Как запустить

Для компиляции используется GCC или Clang:

1. Склонируйте репозиторий: `git clone https://github.com`
2. Перейдите в нужную папку и скомпилируйте файл (например, `gcc back_sqrt.c -o back_sqrt -lm`).
3. Запустите исполняемый файл `./back_sqrt`.

Требуется компилятор GCC (от версии 9.0) или Clang, а также опционально Make.
