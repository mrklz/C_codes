# C Programming Collection

Репозиторий содержит коллекцию программ на языке C, включающую упражнения из классического учебника Брайана Кернигана и Денниса Ритчи (K&R), а также решения задач с Codeforces и Timus Online Judge.

## Структура проекта

<pre>
C_codes/
├── CodeForces/            # Решения задач с платформы Codeforces
├── Timus/                 # Решения задач с Timus Online Judge
└── kr_exercises/          # Упражнения из книги Кернигана и Ритчи
|__ 1000_zadach_po_programmirovaniju/ # Решение задач из сборника
</pre>

## Как запустить

Для сборки и запуска необходим компилятор C:

1. Склонируйте репозиторий: `git clone https://github.com`
2. Перейдите в папку с проектом и скомпилируйте нужный файл с помощью gcc (например, `gcc back_sqrt.c -o back_sqrt -lm`).
3. Запустите полученный исполняемый файл `./back_sqrt`.

## Требования

* Компилятор GCC или Clang
* Текстовый редактор или IDE
